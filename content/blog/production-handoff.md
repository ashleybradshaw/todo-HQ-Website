A project is not done when the UI looks finished. It is done when the handoff station has run: backends, release, and the roster it joins.

> Handoff is part of the factory. It is not a wrap-up email.

**Repdaily**, **ReadyGo**, and **Contentic** each had to clear that station before we would call them in production.
